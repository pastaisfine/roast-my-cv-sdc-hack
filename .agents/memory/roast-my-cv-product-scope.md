---
name: Roast My CV product scope
description: Product audience and required outcomes for the Malaysian graduate CV review tool.
---

Roast My CV is a CV review tool for Malaysian fresh graduates. It scores a CV against dated labour-market demand data, then provides ranked future roles, a reskilling pathway, SDG links, and two AI-disruption scenarios.

**Why:** the user gave this as the product definition.

**How to apply:** Preserve this audience and outcome set in future product work, and distinguish sourced labour-market evidence from heuristic scores and scenarios.

Future Skills Radar is authorised as an extension of this product, not a separate app or backend migration. External radar processing remains synthetic-CV-only; the user subsequently explicitly approved own real CVs for import and local review, with separate opt-in to app-owned CPU OCR. Implementation approval does not authorise paid RunPod provisioning or production deployment. The user wants beginner-friendly explanations and short understanding checks before paid setup.

**Why:** The user explicitly separated implementation approval from infrastructure cost approval and excluded real CV processing by external model APIs and hiring decisions.

**How to apply:** Explain the model, GPU and expected cost before requesting separate provisioning approval. Keep live integration unverified until an approved endpoint passes a smoke test. Never promote editorial AI-exposure drafts to reviewed without explicit human sign-off.
